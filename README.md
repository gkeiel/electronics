# Electronics circuits

A repository with codes, schematic diagrams and simulations of electronic circuits. Each project has its own folder.

The following projects are available:
- [voltage difference detector](./voltage_difference_detector)
- [voltage_signal_conditioner](./voltage_signal_conditioner)
- [voltage source inverter 3-phase SPWM](./voltage_source_inverter_3ph_SPWM)

## Voltage difference detector

A printed circuit board (PCB) design for a voltage difference detector between two input voltages, originally developed for voltage source inverters (VSIs) in parallelism applications. Both the schematic design (.sch) and board layout (.brd) were developed in EAGLE software.
